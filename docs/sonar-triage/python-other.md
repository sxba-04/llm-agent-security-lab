- Windows und endgültige integrierte PR-CI stehen aus

## Grenzen

- Kein Sonar-Befund remote geschlossen, kein Quality Gate oder Regelprofil geändert.
- S8707-Detailbeschreibung war im öffentlichen Analyzer-Repository nicht verfügbar. Bewertung stützt sich auf jede exportierte Datenflussposition, den Quellcode und die dokumentierte Vertrauensgrenze; keine unbekannte Regelausnahme unterstellt.
- Die zehn Komplexitätsbefunde und drei weitere Lesbarkeitsbefunde bleiben ausdrücklich offene Wartungsschuld.
- Zeilenangaben beziehen sich auf die Inventur-Revision; Korrekturen können spätere Zeilen verschieben.
