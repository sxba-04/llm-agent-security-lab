# LLM Agent Security Lab

Praktischer Teil der Studienarbeit von Sebastian Herrmann und Jonah Häuser an der DHBW Karlsruhe, betreut von Ralf Brune.

Das Labor untersucht indirekte Prompt Injection in einem Assistenten für synthetische Service-Tickets. Dieselbe Anwendung vergleicht eine Basisvariante, Inhaltsfilterung, Autorisierung und deren Kombination. Die Werkbank führt derzeit kontrollierte Mock-Versuche aus; daraus folgen noch keine empirischen Aussagen über echte LLMs.
