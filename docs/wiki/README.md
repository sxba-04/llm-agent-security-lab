# Quellen für den Wiki-Einstieg

`Home.md` und `_Sidebar.md` sind die vorbereiteten Inhalte für das separate GitHub-Wiki. Sie verlinken auf die versionierte Projektdokumentation und enthalten keine zweite vollständige Betriebsanleitung.

Diese Dateien werden durch einen normalen Repository-Merge **nicht automatisch** im Wiki veröffentlicht. GitHub verwaltet das Wiki getrennt. Beim erstmaligen Einrichten die Startseite aus `Home.md` und die Seitenleiste aus `_Sidebar.md` übernehmen; eine vorhandene Wiki-Seite zuvor lesen und ihre Inhalte erhalten. Eine abgeschlossene Veröffentlichung ist gesondert zu prüfen und zu dokumentieren.

Die Zielgruppe sind Projektteam und Betreuer. Kontozugänge, Codes, API-Schlüssel, private Belege und ausgefüllte Bewertungen gehören nicht in das öffentliche Wiki. Für einen bestimmten Messstand statt `main` die dokumentierten Links auf dessen Commit oder Tag verwenden.
