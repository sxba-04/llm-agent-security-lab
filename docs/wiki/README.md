# Quellen für den Wiki-Einstieg

`Home.md` und `_Sidebar.md` sind die versionierten Quellen der am 2. November 2026 veröffentlichten Startseite und Navigation des [GitHub-Wikis](https://github.com/sxba-04/llm-agent-security-lab/wiki). Sie verlinken auf die versionierte Projektdokumentation und enthalten keine zweite vollständige Betriebsanleitung.

Diese Dateien werden durch einen normalen Repository-Merge **nicht automatisch** im Wiki veröffentlicht. GitHub verwaltet das Wiki getrennt. Für spätere Aktualisierungen zuerst die vorhandene Wiki-Seite lesen und zwischenzeitliche Beiträge erhalten, dann die geprüften Änderungen aus diesen Quellen übernehmen. Die veröffentlichte Darstellung separat prüfen.

Die Zielgruppe sind Projektteam und Betreuer. Kontozugänge, Codes, API-Schlüssel, private Belege und ausgefüllte Bewertungen gehören nicht in das öffentliche Wiki. Für einen bestimmten Messstand statt `main` die dokumentierten Links auf dessen Commit oder Tag verwenden.
